# Friskis Borg Player

En enkel webbapp för att skapa, spara och köra spinningpass visualiserade med Borgskalan 6–20.

## Funktioner
- Mina pass
- Skapa/redigera pass
- Lokal lagring i webbläsaren
- Borgprofil där bredd = tid och höjd/färg = Borg
- Live-timer med NU-markör
- Start/paus, föregående/nästa block och helskärm
- Ett färdigt 45-minuters demopass

## Publicera med GitHub Pages
1. Skapa ett nytt repository på GitHub, t.ex. `friskis-borg-player`.
2. Ladda upp `index.html`, `style.css` och `app.js` till repositoryts rot.
3. Gå till Settings → Pages.
4. Under Build and deployment välj `Deploy from a branch`.
5. Välj `main` och `/ (root)` och tryck Save.
6. Efter publicering får du en webbadress från GitHub Pages.

Ingen server eller databas behövs i denna första version.
