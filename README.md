# Friskis Training Player — Prototype 2.1.0

Prototype för ledarledda träningspass med dynamiska aktiviteter och intensitetsmodeller.

## Nytt i 2.1.0
- Användarroller: Instruktör, Admin och Super User
- Super User kan ändra roller och användarstatus
- Ägare visas på centrala pass
- Super User kan byta ägare vid redigering
- Instruktörer kan bara redigera sina egna pass
- Duplicering av annans publika pass skapar en privat kopia med den inloggade användaren som ägare
